## 电子工程

[CCtrl-v2.epro2](electronics/jlc_eda_pro/CCtrl-v2.epro2) 是本版的 JLCEDA Pro 电子设计工程。包内包含主板、Handle_node_v2、Encoder_node_v3 和 Encoder_brush 四块板的原理图及 PCB 文档。主板延续原版主控方案；制造文件可在 JLCEDA Pro 中导出。

制板时核对封装、引脚、电源、菊花链方向、滑环与电刷通道、板间连接、DRC/DFM 结果和物料可得性。

## 机械工程

[完整装配 STEP](mechanical/cad/CCtrl-v2-assembly.step) 提供整体模型；[替换件 STEP](mechanical/cad/CCtrl-v2-replacement-parts.step) 包含部分改进零件，用于替换完整模型中的对应零件。装配时在 CAD 中核对对应关系与配合尺寸，详见[机械说明](mechanical/README.md)。
