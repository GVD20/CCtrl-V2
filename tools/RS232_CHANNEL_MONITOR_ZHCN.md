# CCtrl RS232 通道监视器

轻量桌面工具，用于接收 ESP32-S3 主机在 RS232 上输出的 Protocol V2
RoboMaster `0x0302` 二进制帧。

## 启动

```powershell
python tools/rs232_channel_monitor.py
```

也可以直接双击 `tools/start_rs232_channel_monitor.bat`。

依赖 Python 3、Tkinter 和 pyserial。安装 pyserial：

```powershell
python -m pip install pyserial
```

## 使用

1. 在顶部选择 RS232 对应的 COM 口并点击“连接”。串口固定使用 115200 8N1。
2. 左侧显示当前所有通道值。勾选任意一个或多个通道即可绘制曲线。
3. 默认启用“友好值”：Encoder 显示带正负号的角度，Joystick 与 Trigger 显示
   0–100% 行程，状态位和按键显示具体含义。关闭后恢复协议原始整数/十六进制值。
4. “曲线窗口”可选择最近 5–600 秒。修改窗口不会丢失已采集数据。
5. 数值范围差异很大时，可启用“各通道独立缩放”观察每条曲线的相对变化。
6. “暂停曲线”会冻结当前时间窗口，但串口仍在后台采集。暂停后可以切换通道、
   缩放和导出；点击“继续曲线”后回到最新数据，暂停期间的数据不会丢失。
7. “导出当前窗口”只导出当前时间窗内、当前已勾选的通道，CSV 包含本地时间、
   相对时间和帧序号。为保证后续标定和复现，CSV 始终保存协议原始数值，不受
   “友好值”开关影响。
8. “清空历史”会同时清零当前连接的接收帧数、坏帧数和序号缺失统计。

Handle 的三个 TMAG 原始通道已由 ESP32 内部拟合为 0–4095 的 `Trigger` 通道；
工具显示和导出的也是该扳机行程。

工具会在任意字节位置重新寻找 `0xA5` 帧头，并验证 Header CRC8、命令号、30 字节
载荷长度和整帧 CRC16。串口中途连接、半帧和坏帧不会让后续数据显示错位。
